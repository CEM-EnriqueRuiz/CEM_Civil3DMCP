# 0002 — Civil 3D's own port, 8766

**Context.** Upstream's plugin and server defaulted to TCP 8080, the port the Revit MCP (`cem-revit-ai`, CEM_RevitMCP)
connects to. On 2026-10-24 Civil 3D 2027 (acad.exe) held `127.0.0.1:8080`: with Civil 3D open, a Revit MCP call
reached Civil 3D. `setup_claude.ps1` also persisted `CIVIL3D_PORT=8080` in the user's environment, so changing the
code alone would not have moved the plugin.

**Decision.**
1. The default is **8766** in all three places: `PortSetting.Default` (plugin), `DEFAULT_PORT` in
   `src/utils/config.ts` (server), `$DefaultPort` and `-Port`'s default in `setup_claude.ps1`. The harness scripts
   fall back to 8766 too. The machine's ports are listed in [ports](../concepts/ports.md).
2. `CIVIL3D_PORT` still overrides it in the plugin and the server. A value that is not a TCP port (1–65535) falls
   back to the default; before, the server turned `abc` into `NaN` and the plugin accepted 70000.
3. `setup_claude.ps1 -Port <port>` persists `CIVIL3D_PORT` (user environment, and the Claude config entry's `env`)
   only for a port other than the default. Run with the default, it persists nothing and removes a value an earlier
   run left. When the port is taken by something other than acad.exe, setup stops and asks for `-Port`; it no
   longer switches to another port by itself, since that port would have to be persisted.
4. `tests/unit/port-contract.test.mjs` pins the three defaults, and fails on any `8080` left in code.

**Why 8766.** Free on the machine, outside Windows' excluded port ranges, next to the Navisworks MCP's 8765, and
far from common dev ports (8080, 8000, 8888).

**Rejected.** Keeping 8080 and moving the Revit MCP (the Revit MCP is a shipped product feature, and its users
already have 8080 configured); a port chosen at random per start (the server and Claude's config would need a
discovery file, which is a write this repo avoids).

**Consequences.** Existing installs keep 8080 until the persisted variable is removed and the Claude Desktop entry
updated; on the main machine the coordinator did both on 2026-10-24.
