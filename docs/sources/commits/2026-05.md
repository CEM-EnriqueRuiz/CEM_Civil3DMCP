# Upstream history to the fork base

46 commits, all upstream's, none linking an issue. Summarised from `git log` on 2026-10-24.

- **2025-03-19 to 2025-05-16, the Revit MCP origin.** Commits by the `revit-mcp` authors (tool registration, send-code,
  element filters, colour splash, README updates, a MseeP badge): the TypeScript MCP server this repo was copied
  from, the same family as CEM_RevitMCP. Nothing of it survives in the code.
- **2025-06-17, `9506566`** "Adapt MCP server for Autodesk Civil 3D" (an automated agent): the first Civil 3D version.
- **2025-11-04, `806fe79`**: README badge removed.
- **2026-05-14, `ef0e7db`** "domain-based MCP architecture + C# plugin foundation": the C# plugin with a TCP
  JSON-RPC listener (`RpcTcpServer`, `PluginRuntime`, `CivilExecution`) and fixed per-domain handlers.
- **2026-05-15, `d6b953d`** "code execution architecture with Roslyn + skills": 50+ fixed tools replaced by
  `civil3d_execute`, `civil3d_query`, `civil3d_skills`; `RoslynExecutor` with caching and timeout, `ScriptContext`,
  `ScriptSandbox`; 8 handler files removed; 11 skills. Port 8080, `net8.0-windows`, `NETLOAD` by hand.
- **2026-05-15, `40bad8b`, `344ad15`**: licence changed from ISC to MIT; `README_zh.md` deleted. `344ad15` is the base
  of the Cemengal work.

**Decisions inherited:** code execution over fixed tools ([0001](../../decisions/0001-code-execution-architecture.md)).
**Inherited problems later fixed:** the 8080 port shared with the Revit MCP ([0002](../../decisions/0002-own-port-8766.md)).
